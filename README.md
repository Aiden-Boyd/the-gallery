# GalleryGame

Tiny iPhone 3D photo museum prototype.

## First build

1. Install XcodeGen if needed:
   `brew install xcodegen`
2. In Terminal:
   `git clone https://github.com/Aiden-Boyd/the-gallery.git`
3. Open the repo:
   `cd the-gallery`
4. Generate the Xcode project:
   `xcodegen generate`
5. Open:
   `open GalleryGame.xcodeproj`
6. Select your Apple development team and run on an iPhone.

## Controls

- Tap the arrow controls to walk.
- Drag across the 3D view to look around.
- Tap a numbered picture frame.
- Choose any image from Photos.
- The image appears in the frame.
